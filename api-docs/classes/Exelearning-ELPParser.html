ELPParser.php : 51

Parser for eXeLearning project files.

Supported project formats:

  • Legacy .elp packages based on contentv3.xml from eXeLearning 2.x.
  • Modern .elp/.elpx packages based on content.xml (ODE 2.0) from eXeLearning 3+.
